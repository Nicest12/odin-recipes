# Odin Recipes

A simple multi-page recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Project Overview

Odin Recipes is my first multi-page HTML project. The goal of the project is to practice the fundamentals of HTML by creating a recipe website with a homepage and individual recipe pages.

The project currently contains recipes for:

- Noodles
- Fried Rice
- Jollof Rice

## What I Learned

Through this project, I practiced:

- Creating HTML boilerplate
- Using semantic HTML elements
- Working with headings and paragraphs
- Creating links between multiple HTML pages
- Using relative file paths
- Adding images with the `<img>` element
- Using `alt` text for images
- Creating unordered lists with `<ul>`
- Creating ordered lists with `<ol>`
- Creating list items with `<li>`
- Organizing files and directories for a website
- Testing a website locally with a Python HTTP server
